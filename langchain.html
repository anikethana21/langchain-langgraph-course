Prologue

The Paradigm Shift to Agentic AI

Software engineering is experiencing its greatest inflection point in four decades. We have transitioned from deterministic punch-cards to probability distributions, and now to autonomous reasoning loops. Understanding this transition is essential before writing a single line of LangChain code.

🎯 Pedagogical Analogy: The Four Puppeteers of Computing
Think of software history as controlling a marionette puppet:

1. Era 1 (Rule-Based): You tie 1,000 physical strings to every joint. If a gust of wind blows or an obstacle appears that you didn't tie a string for, the puppet collapses onto the stage.
2. Era 2 (Classical ML): You replace strings with elastic rubber bands that learn weight balances from past falls. It balances well on familiar terrain, but cannot read a sign or speak a sentence.
3. Era 3 (Generative AI): You give the puppet a magical voice box. When you ask it a question, it recites the collective wisdom of civilization with astonishing fluency—yet its feet remain nailed to the floorboards. It can talk, but cannot touch the world.
4. Era 4 (Agentic AI): You cut the floorboards, give the puppet hands, eyes, a notebook to plan its journey, and a telephone to call external services. When it stumbles, it inspects its scratchpad, self-corrects its stride, and completes the mission autonomously.
⚖️ The Four Eras of Software Engineering: Architectural Trade-Offs
Dimension Era 1: Procedural Code Era 2: Statistical ML Era 3: Generative LLMs Era 4: Agentic Systems
Primary Mechanism Boolean logic, if/else, loops Feature weights, SGD, trees Transformer attention, next-token prediction ReAct loops, state graphs, tool routing
Adaptability Zero (Crashes on unseen input) Moderate (Interpolates within distribution) High (Zero-shot generalization) Autonomous (Self-correcting, multi-step)
External Action Hardcoded API calls only Passive score output Passive text output (No hands) Dynamic function calling & state persistence
Failure Mode Uncaught exception / crash Drift / misclassification Hallucination / context overflow Runaway tool loops / state divergence
🔬 Under the Hood: What Makes a System Truly "Agentic"?
A system does not become agentic simply by invoking an LLM. An agentic system implements a closed-loop cybernetic feedback cycle consisting of 5 Core Pillars:
  • Perception: Ingesting unstructured multi-modal inputs, environmental variables, and query nuances.
  • Reasoning: Generating multi-step decomposition, hypotheses, and Chain-of-Thought scratchpads before acting.
  • Tool Action: Emitting structured JSON payloads that invoke external APIs, databases, sandboxes, and file systems.
  • Memory & State: Maintaining conversation context, short-term observations, and long-term vectorized episodic storage.
  • Reflection & Self-Correction: Inspecting execution outputs against success criteria and dynamically replanning upon failure.
💡 Developer Empathy: The "Monolithic Prompt" Trap
Every engineer begins their LLM journey by writing a 4,000-word system prompt attempting to instruct a single model how to handle every edge case, parse every format, and verify every fact.

Why you hit a wall: LLM attention is a finite resource. As context length grows, reasoning fidelity degrades exponentially (the "Lost in the Middle" phenomenon). When your monolithic prompt fails, you cannot diagnose which instruction caused the regression.

The Architectural Cure: Decompose monolithic prompts into discrete, specialized agents connected by deterministic state machines and typed schemas.
Module 1

Foundations of Generative AI & LangChain LCEL

To master LangChain, you must demystify how autoregressive language models generate tokens and how LangChain Expression Language (LCEL) transforms disparate runnables into a unified, composable pipeline.

1.1 The Anatomy of Large Language Models (LLMs)

LLMs do not "think" in human concepts. They are probabilistic sequence completion engines operating over discrete tokens. Given an input context sequence x1, x2, ..., xt, the transformer calculates a probability distribution over the entire vocabulary $V$:

Formula 1 P(wi) = exp(zi / T) / Σj exp(zj / T)
🎯 Pedagogical Analogy: The Grand Oracle's Teleprompter
Imagine an oracle standing before an infinite scroll of all human writing. When you hand them a question, they don't consult an internal database of truth. Instead, their hand instantly highlights the top 50,000 words that have historically followed your exact phrasing. Temperature controls whether they strictly pick the single most frequent word (T=0.0) or spin a roulette wheel across the top 20 alternatives (T=1.0).
🔬 Step-by-Step Numerical Walkthrough: Softmax Temperature Scaling
Suppose the model predicts logits for 4 candidate tokens: ["Agent", "Model", "Prompt", "Chain"] with raw output logits $z = [4.0, 2.0, 1.0, 0.5]$.

At T = 1.0 (Standard Softmax):
exp(z) = [54.60, 7.39, 2.72, 1.65]  |  Sum = 66.36
Probabilities: Agent: 82.3%, Model: 11.1%, Prompt: 4.1%, Chain: 2.5%

At T = 0.2 (Greedy / Deterministic Code Mode):
z / 0.2 = [20.0, 10.0, 5.0, 2.5]
exp(z/0.2) = [4.85e8, 22026, 148, 12]
Probabilities: Agent: 99.995%, Model: 0.005%, others ~ 0.0%
The slight gap between 4.0 and 2.0 is amplified into absolute certainty!
⚖️ Hyperparameter Decision Matrix
Parameter Mechanic Low Setting High Setting Best For
Temperature (T) Divides logits before softmax; flattens or sharpens distribution 0.0 - 0.2 (Near-deterministic) 0.8 - 1.2 (Creative, diverse) T=0.0 for SQL/JSON/RAG; T=0.7 for conversational narrative
Top-P (Nucleus) Cumulative probability cutoff; drops tail tokens 0.1 - 0.5 (Strict, focused) 0.9 - 1.0 (Broad vocabulary) 0.9 preserves high coherence while avoiding repetition traps
Top-K Hard integer cutoff for top $K$ candidate tokens K = 1 (Greedy selection) K = 50 - 100 (Rich token pool) Prevents low-probability nonsense words in creative generation

1.4 LangChain & LCEL (LangChain Expression Language)

In modern LangChain, pipelines are not constructed via legacy classes like LLMChain. They are composed via LCEL using the overloaded bitwise OR pipe operator (|), mapping directly to the Runnable Protocol.

🎯 Pedagogical Analogy: Unix Pipes & The Factory Conveyor Belt
Just like Unix allows piping standard output to standard input (cat logs.txt | grep "404" | wc -l), LCEL standardizes inputs and outputs across all AI components. A PromptTemplate takes a dictionary and emits a PromptValue. A ChatModel takes a PromptValue and emits an AIMessage. An OutputParser takes an AIMessage and emits a clean string or Pydantic object. Because every component honors the Runnable interface, they snap together effortlessly.
💡 Developer Empathy: Why Did My Chain Return NoneType?
The most common mistake when starting with LCEL is passing non-runnable Python functions directly into the pipe. If you write prompt | my_custom_func | model, LangChain will crash because my_custom_func does not implement .invoke() or .batch().

The Fix: Wrap any raw Python function in RunnableLambda(my_custom_func) or pass values through RunnablePassthrough().
lcel_foundations.py — Complete LCEL Pipeline
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

# 1. Define Prompt Template with System Persona and Human Variable
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are an elite AI Systems Architect. Provide direct, highly technical, actionable breakdowns."),
    ("human", "Explain the difference between {topic_a} and {topic_b} in modern AI engineering.")
])

# 2. Instantiate Model with Deterministic Temperature
model = ChatOpenAI(model="gpt-4o", temperature=0.0)

# 3. Instantiate Output Parser
parser = StrOutputParser()

# 4. Compose via LCEL Pipe Operator
# Flow: Dict -> PromptTemplate -> ChatModel -> StrOutputParser -> String
chain = prompt | model | parser

# 5. Execute via Runnable Protocol
if __name__ == "__main__":
    response = chain.invoke({
        "topic_a": "LangChain LCEL",
        "topic_b": "LangGraph StateGraph"
    })
    print("--- Output from LCEL Chain ---")
    print(response)
Module 2

The Retrieval-Augmented Generation (RAG) Architecture

RAG bridges the three fatal flaws of standalone LLMs: Static Knowledge Cutoffs, Hallucinations, and Enterprise Data Blindspots. Rather than retraining weights, RAG provides relevant contextual facts dynamically at inference time.

The 5 Core Pillars of Production RAG

🎯 Pedagogical Analogy: Open-Book Bar Exam vs Memorization
Asking a vanilla LLM about internal company policy is like asking a law student to take the Bar Exam with their eyes closed, relying purely on memory from two years ago. RAG is turning the exam into an open-book test: when a question arrives, a high-speed research paralegal (Retriever) pulls the exact three relevant statutory clauses from the law library and places them directly on the student's desk before they answer.
⚖️ Enterprise Knowledge Strategies: Prompting vs Fine-Tuning vs RAG
Strategy Setup Cost Update Latency Hallucination Defense Data Privacy & Governance
Prompt Stuffing Zero Instant Low (Prone to context overflow & loss) Full context transmitted per request
Fine-Tuning Very High ($1k - $50k) Hours to Days Poor (Memorization does not guarantee accuracy) Data baked irreversibly into weights
Production RAG Moderate (Vector DB) Seconds (Near real-time ingest) High (Grounded in cited evidence) Document-level ACLs & role-based access

Pillars 1 & 2: Document Loading & Chunking Mathematics

Raw documents cannot be fed into vector stores as massive blobs. They must be parsed and split using the Recursive Character Text Splitter, adhering to the mathematical stride formula:

Formula 4 Effective_Stride = Chunk_Size - Chunk_Overlap
🎯 Pedagogical Analogy: Splicing Movie Film Frames
If you cut a film reel strictly every 1,000 frames with zero overlap, an actor speaking a sentence right across the 1,000th frame gets their sentence guillotined in half. Part 1 ends with "The suspect fled towards the..." and Part 2 starts with "...harbor at midnight." Neither chunk understands where the suspect went! A 200-character overlap stitches the frames together so no semantic thought is severed.
💡 Developer Empathy: The Table Splitting Nightmare
Standard character text splitters treat markdown tables and financial balance sheets like plain text. If a split occurs halfway down a table, Chunk 2 receives rows of numbers with completely missing column headers! The vector embedding for Chunk 2 becomes semantic noise.

Best Practice: Use table-aware parsers or format tables as individual JSON key-value blocks prior to chunking.

from langchain_community.document_loaders import PyPDFLoader, YoutubeLoader

text_splitter = RecursiveCharacterTextSplitter(

# 3. Perform Chunking

print(f"Generated {len(chunks)} contextual chunks from {len(pdf_docs)} pages.")
print(f"Sample Chunk 0 Metadata: {chunks[0].metadata}")
print(f"Sample Chunk 0 Preview: {chunks[0].page_content[:200]}...")

Pillars 3, 4 & 5: High-Dimensional Embeddings & Vector Stores

Embeddings map textual chunks into an N-dimensional geometric space where conceptual similarity translates into spatial proximity, calculated via Cosine Similarity:

Formula 2 Cosine_Similarity(A, B) = (A · B) / (||A|| * ||B||)
🎯 Pedagogical Analogy: Flashlight Beams in Dense Fog
Imagine two explorers shining flashlights into the night fog from the same position. Euclidean distance measures the straight-line distance between the tips of their light beams (which gets ruined if one flashlight is twice as powerful as the other). Cosine similarity measures only the angle between their beams! If both flashlights point directly north, $ heta = 0^\circ$ and $\cos(0) = 1.0$, regardless of whether one beam is short and the other is long.
🔬 2D Numerical Walkthrough: Calculating Cosine Similarity Step-by-Step
Let Query Vector $Q = [0.8, 0.6]$ and Candidate Document Chunk $D = [0.6, 0.8]$.

1. Dot Product: $Q \cdot D = (0.8 imes 0.6) + (0.6 imes 0.8) = 0.48 + 0.48 = 0.96$
2. Magnitude of Q: $\|Q\| = \sqrt{0.8^2 + 0.6^2} = \sqrt{0.64 + 0.36} = \sqrt{1.0} = 1.0$
3. Magnitude of D: $\|D\| = \sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64} = \sqrt{1.0} = 1.0$
4. Cosine Similarity: $\cos( heta) = rac{0.96}{1.0 imes 1.0} = 0.96$
Result: 0.96 indicates an extraordinarily close semantic match ($pprox 16.2^\circ$ angle)!

complete_rag_chain.py — Production LCEL RAG Pipeline
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

# 1. Create Vector Store with Embeddings
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=embeddings,
    collection_name="enterprise_knowledge"
)

# 2. Expose as Standard Retriever (Top-3 nearest neighbors)
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})

# 3. Document Formatter Helper Function
def format_docs(docs):
    return "\n\n---\n\n".join([doc.page_content for doc in docs])

# 4. Strict Grounding RAG Prompt Template
rag_prompt = ChatPromptTemplate.from_template("""
You are an expert enterprise research assistant.
Answer the question based STRICTLY and SOLELY on the provided context below.
If the answer cannot be deduced from the context, state: "I do not have sufficient information in the verified knowledge base."
Do not speculate or extrapolate.

CONTEXT:
{context}

QUESTION:
{question}

GROUNDED ANSWER:
""")

# 5. End-to-End LCEL Composition
# Flow: Takes {"question": str} -> Retrieves & formats docs -> Populates prompt -> Generates -> Parses
rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt
    | ChatOpenAI(model="gpt-4o", temperature=0.0)
    | StrOutputParser()
)

# 6. Execute Query
if __name__ == "__main__":
    query = "What is the penalty for late fee submission?"
    answer = rag_chain.invoke(query)
    print("=== RAG Response ===")
    print(answer)

2.7 Advanced RAG: MMR (Maximal Marginal Relevance)

Standard Top-K retrieval often returns five virtually identical paragraphs from different pages of a document. Maximal Marginal Relevance (MMR) solves this by balancing similarity to query with diversity against already selected chunks:

Formula 3 MMR = argmax [ λ * Sim1(d_i, Q) - (1 - λ) * max Sim2(d_i, d_j) ]
🎯 Pedagogical Analogy: Assembling an Expert Taskforce
If you need 3 advisors to review a complex legal case, Naive Top-K hires the 3 best corporate tax lawyers in the world. They all say the exact same thing! MMR hires the best corporate tax lawyer, but then penalizes anyone who has the same expertise, deliberately selecting a criminal defense attorney and a constitutional scholar for the remaining two seats to maximize broad perspective.
Module 3

Tools, Function Calling & Single-Agent Systems

Giving an LLM "hands" transforms it from a passive predictor into an active agent. By binding tools described via JSON Schema, the LLM emits structured tool call requests which your application executes, feeding the observations back into the context.

🎯 Pedagogical Analogy: The Armchair Scholar Given a Calculator
A pure LLM attempting to multiply 48291 * 92812 will hallucinate an answer because it is guessing next tokens based on probability. Binding a tool is handing the scholar a physical scientific calculator. When asked to multiply, the scholar pauses, punches the numbers into the calculator, reads the digital screen, and reports the 100% verified result.
💡 Developer Empathy: The Vague Docstring Pitfall
LLMs do not see your Python code; they only see the tool's name, docstring, and argument schema. If your docstring is "Performs search", the LLM will fail to understand when to call it or pass malformed arguments.

Golden Rule: Write your tool docstring as if you are explaining the function to a junior intern on their first day: explain what it does, what inputs it requires, what format it returns, and when NOT to use it.
agent_tools_react.py — Tool Definition & Execution Loop
from langchain_core.tools import tool
from pydantic import BaseModel, Field
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage, ToolMessage

# 1. Define Strict Pydantic Schema
class StockPriceInput(BaseModel):
    ticker: str = Field(description="The 1-5 letter stock ticker symbol, e.g., AAPL, NVDA, TSLA")

@tool("get_stock_price", args_schema=StockPriceInput)
def get_stock_price(ticker: str) -> str:
    """Fetches real-time price and market stats for a given stock ticker."""
    mock_data = {"AAPL": "$224.50", "NVDA": "$128.20", "TSLA": "$245.10"}
    price = mock_data.get(ticker.upper(), "Ticker not found.")
    return f"Stock: {ticker.upper()} | Real-time Price: {price}"

# 2. Bind Tools to LLM
model = ChatOpenAI(model="gpt-4o", temperature=0.0)
tools = [get_stock_price]
tools_dict = {t.name: t for t in tools}
model_with_tools = model.bind_tools(tools)

# 3. Finite State Machine: The ReAct Execution Loop
messages = [
    SystemMessage(content="You are an expert financial analyst. Use available tools to look up real data."),
    HumanMessage(content="What is the current stock price of Apple and Nvidia?")
]

print("Starting Agent Loop...")
while True:
    response = model_with_tools.invoke(messages)
    messages.append(response)
    
    # If the model does not request any tool calls, it has reached its final answer!
    if not response.tool_calls:
        print("\n=== Final Agent Answer ===")
        print(response.content)
        break
        
    # Execute requested tools
    for tool_call in response.tool_calls:
        fn_name = tool_call["name"]
        fn_args = tool_call["args"]
        call_id = tool_call["id"]
        
        print(f"-> Agent invoked tool: {fn_name}({fn_args})")
        tool_result = tools_dict[fn_name].invoke(fn_args)
        
        # Append observation as ToolMessage
        messages.append(ToolMessage(content=str(tool_result), tool_call_id=call_id))

project1_multi_agent/cache_manager.py — Binary Persistence Layer
import os
import pickle
import hashlib
from typing import Any, Optional

CACHE_DIR = os.path.join(os.path.dirname(__file__), ".cache")
os.makedirs(CACHE_DIR, exist_ok=True)

def _generate_key(prefix: str, payload: str) -> str:
    hasher = hashlib.sha256()
    hasher.update(payload.encode("utf-8"))
    return f"{prefix}_{hasher.hexdigest()[:16]}.pkl"

def save_to_cache(prefix: str, payload: str, data: Any) -> str:
    """Serializes Python data structure directly to .pkl file."""
    filepath = os.path.join(CACHE_DIR, _generate_key(prefix, payload))
    with open(filepath, "wb") as f:
        pickle.dump(data, f, protocol=pickle.HIGHEST_PROTOCOL)
    return filepath

def load_from_cache(prefix: str, payload: str) -> Optional[Any]:
    """Deserializes data from .pkl if it exists; returns None on cache miss."""
    filepath = os.path.join(CACHE_DIR, _generate_key(prefix, payload))
    if os.path.exists(filepath):
        with open(filepath, "rb") as f:
            return pickle.load(f)
    return None
project1_multi_agent/tools.py — Cached Web Fetch Tools
import os
import requests
from bs4 import BeautifulSoup
from langchain_core.tools import tool
from cache_manager import load_from_cache, save_to_cache

@tool("web_search")
def web_search(query: str) -> str:
    """Searches the web for relevant URLs based on a query."""
    cached = load_from_cache("search", query)
    if cached:
        return f"[FROM PKL CACHE]\n{cached}"
        
    simulated_results = (
        f"1. https://en.wikipedia.org/wiki/LangChain - LangChain Architecture Overview\n"
        f"2. https://arxiv.org/abs/2305.10601 - Multi-Agent System Methodologies\n"
        f"3. https://python.langchain.com - Official Documentation"
    )
    save_to_cache("search", query, simulated_results)
    return simulated_results

@tool("scrape_webpage")
def scrape_webpage(url: str) -> str:
    """Fetches raw text content from a verified URL."""
    cached = load_from_cache("url", url)
    if cached:
        return f"[FROM PKL CACHE]\n{cached}"
        
    try:
        resp = requests.get(url, timeout=5)
        soup = BeautifulSoup(resp.text, "html.parser")
        text = soup.get_text(separator=" ", strip=True)[:2500]
    except Exception as e:
        text = f"Simulated content extracted for {url}: LangGraph introduces cyclical graphs for agent loops."
        
    save_to_cache("url", url, text)
    return text

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from tools import web_search, scrape_webpage

def build_search_agent():
    """Constructs Agent 1: Scout responsible for search queries."""
    prompt = ChatPromptTemplate.from_messages([
        ("system", "You are the Lead Intelligence Scout. Search the web and return the top 3 high-authority URLs."),
        ("human", "Research Topic: {topic}")
    ])
    model = ChatOpenAI(model="gpt-4o", temperature=0.0).bind_tools([web_search])
    return prompt | model

def build_read_agent():
    """Constructs Agent 2: Analyst responsible for digesting web content."""
    prompt = ChatPromptTemplate.from_messages([

    ])
    model = ChatOpenAI(model="gpt-4o", temperature=0.0).bind_tools([scrape_webpage])
    return prompt | model

def build_writer_agent():
    """Constructs Agent 3: Executive Editor responsible for final technical report."""

        ("human", "Research Notes:\n{notes}\n\nCompile Executive Report:")
    ])
    model = ChatOpenAI(model="gpt-4o", temperature=0.2)

project1_multi_agent/pipelines.py — Pipeline Orchestrator
from agents import build_search_agent, build_read_agent, build_writer_agent
from cache_manager import save_to_cache, load_from_cache

def run_research_pipeline(topic: str):
    print(f"=== INITIATING MULTI-AGENT RESEARCH PIPELINE: {topic} ===")
    
    # Check if whole pipeline was previously saved
    cached_report = load_from_cache("full_report", topic)
    if cached_report:
        print("[CACHE HIT] Returning serialized final report instantly from .pkl!")
        return cached_report
        
    # Phase 1: Search Agent
    print("\n[Agent 1: Searcher] Discovering authority sources...")
    search_agent = build_search_agent()
    search_res = search_agent.invoke({"topic": topic})
    urls = search_res.content if search_res.content else "https://en.wikipedia.org/wiki/LangChain"
    print(f"-> Scout found: {urls[:100]}...")
    
    # Phase 2: Read Agent
    print("\n[Agent 2: Reader] Digesting source contents...")
    read_agent = build_read_agent()
    read_res = read_agent.invoke({"urls": urls})
    notes = read_res.content if read_res.content else "LangChain enables modular AI pipelines with stateful loops."
    print("-> Analyst synthesized core notes.")
    
    # Phase 3: Writer Agent
    print("\n[Agent 3: Writer] Compiling final publication report...")
    writer_agent = build_writer_agent()
    final_report = writer_agent.invoke({"notes": notes}).content
    
    # Persist Final Result to .pkl
    save_to_cache("full_report", topic, final_report)
    print("-> Pipeline complete! Output cached to disk as .pkl.")
    return final_report

if __name__ == "__main__":
    report = run_research_pipeline("Agentic State Machines in LangGraph")
    print("\n================ FINAL REPORT ================")
    print(report)

import os
import pickle
import hashlib
from typing import Any, Optional

CACHE_DIR = os.path.join(os.path.dirname(__file__), ".pkl_cache")
os.makedirs(CACHE_DIR, exist_ok=True)

def get_cache_path(video_id: str, artifact_type: str) -> str:
    safe_name = f"{video_id}_{artifact_type}.pkl"
    return os.path.join(CACHE_DIR, safe_name)

def dump_artifact(video_id: str, artifact_type: str, data: Any) -> str:
    path = get_cache_path(video_id, artifact_type)
    with open(path, "wb") as f:
        pickle.dump(data, f, protocol=pickle.HIGHEST_PROTOCOL)
    print(f"[CACHE EXPORT] Serialized {artifact_type} for {video_id} -> {path}")
    return path

def load_artifact(video_id: str, artifact_type: str) -> Optional[Any]:
    path = get_cache_path(video_id, artifact_type)
    if os.path.exists(path):
        with open(path, "rb") as f:
            data = pickle.load(f)
        print(f"[CACHE HIT] Loaded {artifact_type} for {video_id} directly from disk!")
        return data
    return None

import numpy as np
from typing import List, Dict, Any, Tuple
from langchain_openai import OpenAIEmbeddings
from ingest import get_video_transcript
from cache_manager import load_artifact, dump_artifact

class VideoVectorIndex:
    def __init__(self, texts: List[str], embeddings_matrix: np.ndarray, metadata: List[Dict[str, Any]]):
        self.texts = texts
        self.matrix = embeddings_matrix  # Shape: (N, D)
        self.metadata = metadata

    def search(self, query_vector: np.ndarray, k: int = 2) -> List[Tuple[Dict[str, Any], float]]:
        norm_matrix = np.linalg.norm(self.matrix, axis=1)
        norm_q = np.linalg.norm(query_vector)
        dot_products = np.dot(self.matrix, query_vector)
        similarities = dot_products / (norm_matrix * norm_q + 1e-9)
        
        top_indices = np.argsort(similarities)[::-1][:k]
        return [(self.metadata[i], float(similarities[i])) for i in top_indices]

def get_or_build_video_index(video_id: str) -> VideoVectorIndex:
    cached_index = load_artifact(video_id, "vector_index")
    if cached_index:
        return cached_index

    transcript = get_video_transcript(video_id)
    texts = [item["text"] for item in transcript]
    
    print("[EMBEDDINGS] Computing vector embeddings via OpenAI...")
    emb_client = OpenAIEmbeddings(model="text-embedding-3-small")
    vectors = emb_client.embed_documents(texts)
    matrix = np.array(vectors)

    index = VideoVectorIndex(texts, matrix, transcript)
    dump_artifact(video_id, "vector_index", index)
    return index
project2_video_assistant/tools.py — Timestamp Tools
from langchain_core.tools import tool
from langchain_openai import OpenAIEmbeddings
import numpy as np
from vector_store import get_or_build_video_index

CURRENT_VIDEO_ID = "dQw4w9WgXcQ"

def format_timestamp(seconds: float) -> str:
    m = int(seconds // 60)
    s = int(seconds % 60)
    return f"{m:02d}:{s:02d}"

@tool("find_video_timestamp")
def find_video_timestamp(query: str) -> str:
    """Finds the exact minute:second timestamp where a concept is discussed in the video."""
    index = get_or_build_video_index(CURRENT_VIDEO_ID)
    emb_client = OpenAIEmbeddings(model="text-embedding-3-small")
    query_vec = np.array(emb_client.embed_query(query))
    
    results = index.search(query_vec, k=2)
    output = []
    for meta, score in results:
        ts = format_timestamp(meta["start"])
        output.append(f"[{ts}] (Score: {score:.3f}): \"{meta['text']}\"")
    return "\n".join(output)

from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage, ToolMessage
from tools import find_video_timestamp

def ask_video_assistant(user_query: str):
    tools = [find_video_timestamp]
    tools_dict = {t.name: t for t in tools}
    model = ChatOpenAI(model="gpt-4o", temperature=0.0).bind_tools(tools)
    
    messages = [
        SystemMessage(content=(
            "You are an AI Video Assistant. When users ask questions about the video content, "
            "always invoke the `find_video_timestamp` tool to find the exact timestamp. "
            "Cite timestamps in [MM:SS] format with direct quotes."
        )),
        HumanMessage(content=user_query)
    ]
    
    while True:
        resp = model.invoke(messages)
        messages.append(resp)
        if not resp.tool_calls:
            return resp.content
            
        for call in resp.tool_calls:
            result = tools_dict[call["name"]].invoke(call["args"])
            messages.append(ToolMessage(content=str(result), tool_call_id=call["id"]))

if __name__ == "__main__":
    print("=== Asking Video Assistant ===")
    response = ask_video_assistant("At what time does the instructor explain cosine similarity?")
    print(response)

Summary & Key Mathematical Formulas

A consolidated engineering reference of the fundamental mathematical equations governing GenAI, RAG, and retrieval algorithms.

Formula 1
Softmax Probability Distribution with Temperature Scaling:
P(w_i) = exp(z_i / T) / Σ_{j=1}^{|V|} exp(z_j / T)
Where $z_i$ is the unnormalized logit for token $i$, $T$ is temperature, and $|V|$ is vocabulary size.
Formula 2
High-Dimensional Cosine Similarity:
cos(θ) = (A · B) / (||A|| * ||B||) = Σ(A_i * B_i) / ( √ΣA_i^2 * √ΣB_i^2 )
Measures the angle between normalized semantic embeddings in $\mathbb{R}^D$ space, bounded between -1.0 and +1.0.
Formula 3
Maximal Marginal Relevance (MMR):
MMR = argmax_{d_i ∈ D \setminus S} [ λ * Sim_1(d_i, Q) - (1 - λ) * max_{d_j ∈ S} Sim_2(d_i, d_j) ]
Balances query relevance against redundancy. $\lambda = 0.5$ balances diversity and accuracy equally.
Formula 4
Text Splitter Effective Stride:
Effective_Stride = Chunk_Size - Chunk_Overlap
Defines the sliding stride index across character streams to prevent boundary clipping.
