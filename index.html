🤖 Module 1.1

The Anatomy of Large Language Models

How modern transformers (GPT-4o, Claude, Gemini, Llama) predict the next token using the autoregressive probability framework.

📝
Tokenization

Text is converted into numerical IDs called tokens.

Token Rule of Thumb
1 token ≈ 0.75 words ≈ 4 characters

The sentence "AI agents are powerful tools" ≈ 6 tokens.

🎯
Next-Token Prediction
Autoregressive Prediction
P( wt+1 | w1, w2, ..., wt )
"Given all previous tokens, compute the probability of every next token in vocabulary V"
🏛️
The Four Eras of Software Engineering
Era 1 Deterministic Programming — Input → Explicit If/Else Rules → Output. Brittle, zero generalization.
Era 2 Classical ML — Data + Labels → Trained Weights → Predictions. Statistical, manual feature engineering.
Era 3 Generative AI (LLMs) — Prompt → Pre-trained Transformer → Generated Text. Semantic understanding, static knowledge.
Era 4 Agentic AI — Goal → Perception → Planning → Tool Execution → Reflection → Result. Dynamic, self-correcting.

P(wᵢ) = exp(zᵢ / T) / Σ exp(zᵵ / T)
zᵢ = raw logit score  ·  T = temperature  ·  Sum over all tokens j in vocabulary V

✍️ Module 1.3

Prompt Engineering

The 5 structural blocks every production agent prompt must contain.

1️⃣ PERSONA & ROLE — Who is the agent?

▼

Set the agent's identity and domain expertise at the very start of the system prompt.

SYSTEM PROMPT
You are an expert Research Analyst Agent specializing in financial markets.

2️⃣ OBJECTIVE & TASK — What must be done?

▼
SYSTEM PROMPT
Analyze quarterly revenue reports and identify growth bottlenecks with evidence.

3️⃣ TOOLS & CONSTRAINTS — What can / can't it do?

▼
SYSTEM PROMPT
Tools: [web_search, calculator, query_db] - ONLY use retrieved facts - Do NOT fabricate numbers - State "DATA_UNAVAILABLE" if missing

4️⃣ REASONING PROCESS — Chain of Thought

▼

Force the model to reason step-by-step BEFORE answering. Reduces hallucinations significantly.

SYSTEM PROMPT
Think step-by-step BEFORE answering: 1. Parse ticker and fiscal quarters 2. Formulate tool queries 3. Compute YoY % delta with calculator

5️⃣ OUTPUT FORMAT — JSON Schema

▼
JSON SCHEMA
{ "ticker": string, "yoy_growth": float, "drivers": [string], "risks": [string] }
🔗 Module 1.4

LangChain & LCEL

LangChain Expression Language chains components using the pipe | operator.

⚛️
The Chain Formula
Chain = PromptTemplate | ChatModel | OutputParser
Each component is a Runnable. They compose and stream automatically via the LCEL protocol.
Python — LCEL Chain
from langchain_core.prompts import ChatPromptTemplate from langchain_openai import ChatOpenAI prompt = ChatPromptTemplate.from_messages([ ("system", "You answer in concise bullet points."), ("human", "{question}") ]) chain = prompt | ChatOpenAI(model="gpt-4o", temperature=0) | StrOutputParser() result = chain.invoke({"question": "Explain RAG in 3 sentences."})
📚 Module 2.1

Why RAG? The Triple Limitation Problem

Standard LLMs suffer from 3 critical flaws. RAG solves all three without expensive fine-tuning.

🪄
Hallucinations

LLMs optimize for fluency, not truth. When uncertain, they output confident falsehoods. RAG grounds answers in retrieved verified facts.

📅
Knowledge Cutoff

Models know nothing after training ends. RAG injects live, up-to-date documents at query time without any retraining.

🔒
Private Data Blindness

Base models cannot see your internal wikis or databases. RAG retrieves proprietary context and injects it into the prompt dynamically.

Document Loading & Chunking

LLMs can't ingest 500-page books. Recursive splitting preserves sentence boundaries with configurable overlap.

📂
Document Loaders
PyPDFLoader — Extracts text + page metadata from PDF files.
WebBaseLoader — Fetches & strips clean text from URLs.
YoutubeLoader — Fetches video transcripts with time offsets.
✂️
Why Overlap is Mandatory

Without overlap, facts split across chunk boundaries are lost:

Chunk 1: "...The total net profit was"
Chunk 2: "$42.5 million in Q3..."
✓ With overlap = full fact preserved!

📐 Module 2.4

Vector Embeddings & Cosine Similarity

Texts become vectors in high-dimensional space. Similar meanings → similar directions → high cosine score.

Formula 2: Vector Cosine Similarity
CosineSim(A, B) = (A · B) / (||A|| × ||B||)
A · B = Dot Product (Σ Aᵢ×Bᵢ)  |  ||A|| = √(Σ Aᵢ²)  |  Range: -1.0 to +1.0

⚖️ Module 2.7

MMR — Maximal Marginal Relevance

Eliminates redundant chunk retrieval by balancing relevance to query vs. diversity among selected chunks.

Formula 3: Maximal Marginal Relevance (MMR)
MMR = argmax[ λ · Sim₁(dᵢ, q) − (1−λ) · max Sim₂(dᵢ, dᵵ) ]
λ=1 → pure relevance (Top-K)  ·  λ=0.7 → sweet spot  ·  λ=0 → pure diversity

🔧 Module 3.1–3.2

Tools & Function Calling

LLMs issue structured tool-call requests. Your Python runtime executes the actual function and returns results.

The 5-Step Tool Call Loop
1

Developer registers tools

Each tool has name, description, and Pydantic JSON schema. Passed to LLM on invocation.

2

LLM returns Tool Call Request

{"name":"get_stock_quote","args":{"ticker":"AAPL"}}

3

Python runtime executes the function

Your code calls get_stock_quote("AAPL") → returns "$224.50"

4

Result packaged into ToolMessage

The observation is appended to message history and sent back to the LLM.

5

LLM reads result & drafts final response

With the tool observation in context, the model produces a grounded, factual answer.

🕷 Module 4.3

LangGraph Architecture

Agent workflows as directed state graphs: Nodes execute logic, Edges route control, State persists data.

📦
State

A TypedDict/Pydantic schema shared across ALL nodes. Single source of truth for the entire graph run.

⚙️
Nodes

Python functions that receive current State, perform computation or call an LLM, and return state updates.

↔️
Edges

Deterministic connections OR conditional router functions returning next node name based on state values.

Animated Graph: Deep Research Multi-Agent Pipeline

↓
📋 Planner Node
↓
🔍 Researcher Node

✏️ Drafter Node

🔎 Critic / Evaluator

from langgraph.graph import StateGraph, START, END graph = StateGraph(State) graph.add_node("planner", planner_node) graph.add_node("researcher", research_node) graph.add_edge(START, "planner") graph.add_conditional_edges("critic", route_critic) app = graph.compile()
🗺️ Module 4.1–4.2

Multi-Agent Topologies

Different architectures for different problem shapes. Pick the right topology every time.

1. Sequential Pipeline

Linear hand-off between specialist agents.

Planner → Researcher ↓ Writer → Output

2. Hierarchical Supervisor

Central orchestrator routes to subagents.

[Supervisor] / | \ Web DB Code

3. Generator-Critic Loop

Writer loops with Critic until quality passes.

[Writer] → Draft ↑ ↓ [Revise] ← [Critic] ↓ Pass [Output]

4. Parallel Fan-Out

Multiple branches run simultaneously.

[START] / | \ Tox Copy Cult \ | / [Reducer]

5. Conditional RAG Router

Classifier routes to matching knowledge base.

[Classifier] / | \ Acad Fee General \ | / [Response]

6. Human-in-the-Loop

Graph pauses, human reviews, then resumes.

[Writer] → interrupt() ↓ Human Input ↓ Command(resume=...)

📋 Module 6

The 6-Step Agent Design Blueprint

The universal framework for designing any AI agent from scratch.

1

Define Domain, Objective & Persona

What is the exact goal? What domain expertise does the agent need? What are its hard constraints?

2

Inventory the Action Space (Tools)

What external systems must it touch? Define strict Pydantic schemas and comprehensive docstrings for every tool.

3

Knowledge & Context Grounding (RAG)

Configure loaders → chunking → vector store → MMR retriever → .pkl cache layer.

4

Select Cognitive Architecture

Linear → LCEL  |  Dynamic tools → ReAct Agent  |  Multi-step/iterative → LangGraph StateGraph

5

Design State Schema & Memory

What parameters persist across reasoning cycles? Serialize checkpoints to .pkl for session persistence.

6

Guardrails, Recursion Caps & Recovery

Set max_iterations to prevent infinite loops. Catch all tool exceptions and return clean error strings to the LLM.

📐 Quick Reference

Key Formulas Cheatsheet

All 4 core formulas from the course at a glance.

1. Softmax with Temperature Scaling
P(wᵢ) = exp(zᵢ / T) / Σᵵ∈V exp(zᵵ / T)
T→0 = greedy/deterministic  ·  T=1 = standard  ·  T>1 = creative/random
2. Vector Cosine Similarity
CosineSim(A,B) = (A·B) / (||A|| × ||B||) = Σ(AᵢBᵢ) / √(ΣAᵢ²) × √(ΣBᵢ²)
+1 = identical  ·  0 = orthogonal/unrelated  ·  -1 = opposite
3. Maximal Marginal Relevance (MMR)
MMR = argmaxᵢ∈D\S [ λ·Sim₁(dᵢ,q) − (1−λ)·maxᵵ∈S Sim₂(dᵢ,dᵵ) ]
λ=1 pure relevance  ·  λ=0.7 sweet spot  ·  λ=0 pure diversity
4. ReAct Cognitive Loop
Input → ( Thought → Action → Observation )* → Final Answer
* = repeats N times  ·  max_iterations guards against infinite loops
