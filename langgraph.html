Module 1

1. State Modeling: states.py

State is the central blackboard of LangGraph. TypedDict provides lightweight execution, while Pydantic enforces strict runtime validation.

1. TypedDict Approach (Standard)

Standard in LangGraph for low overhead. Type hints are analyzed at graph compilation time, and nodes pass standard Python dictionaries.

2. Pydantic Approach (Runtime Validated)

Enforces runtime validation, custom field validators (e.g. score >= 0), and strict serialization contracts. Ideal for production APIs.

Python — states.py
import os from typing import TypedDict from pydantic import BaseModel, field_validator # 1) TypedDict Approach (Most Common in LangGraph) class State(TypedDict): topic: str summary: str score: int # 2) Pydantic Approach (Data validation and type checking at runtime) class PydanticState(BaseModel): topic: str score: int summary: str = "" @field_validator("score") def score_positive(cls, v): if v < 0: raise ValueError("Score must be positive") return v

Project 1: Sequential Workflow (sequential_base.py)

Linear hand-off where each node processes the previous node's output. Pipeline: Raw Text → Copyeditor → Video Scriptwriter Hook → Indian Hinglish Translator.

[START] ──> [Copyeditor Node] ──> [Scriptwriter Node] ──> [Hinglish Translator] ──> [END]
Python — sequential_base.py (Complete Production Code)
import os from typing import TypedDict from dotenv import load_dotenv from langchain_groq import ChatGroq from langgraph.graph import StateGraph, START, END load_dotenv() # Step 1: Define Pipeline State class pipelinestate(TypedDict): raw_input: str edited_text: str script_text: str final_output: str # Central LLM llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.7) # Step 2: Define Nodes def editor_node(state: pipelinestate) -> dict: """Stage 1: Cleans up grammar, removes typos, and refines the tone.""" print("\n--- [Stage 1] Executing Copyeditor Node ---") prompt = ( "You are an expert copyeditor. Clean up the following raw text. " "Fix grammar, improve vocabulary, and structure it into clear thoughts.\n\n" f"Raw Input:\n{state['raw_input']}" ) res = llm.invoke(prompt) return {"edited_text": res.content} def scriptwriter_node(state: pipelinestate) -> dict: """Stage 2: Turns copyedited text into an engaging YouTube Shorts/Reels script with hook.""" print("\n--- [Stage 2] Executing Video Scriptwriter Node ---") prompt = ( "You are a viral YouTube Shorts and Reels scriptwriter. " "Take this edited text and convert it into a 30-second video script.\n" "Format requirements:\n" "- High-retention 3-second HOOK\n" "- Rapid-fire BODY (bullet points with visual cues in brackets)\n" "- Clear CALL TO ACTION (CTA)\n\n" f"Content:\n{state['edited_text']}" ) res = llm.invoke(prompt) return {"script_text": res.content} def translator_node(state: pipelinestate) -> dict: """Stage 3: Converts the script into casual Indian Hinglish.""" print("\n--- [Stage 3] Executing Hinglish Translator Node ---") prompt = ( "You are an expert content creator in India. " "Translate and adapt this video script into natural, energetic Hinglish " "(Hindi written in Roman English script like Gen-Z speaks).\n" "Keep technical terms in English.\n\n" f"Script:\n{state['script_text']}" ) res = llm.invoke(prompt) return {"final_output": res.content} # Step 3: Build Graph builder = StateGraph(pipelinestate) builder.add_node("editor", editor_node) builder.add_node("scriptwriter", scriptwriter_node) builder.add_node("translator", translator_node) builder.add_edge(START, "editor") builder.add_edge("editor", "scriptwriter") builder.add_edge("scriptwriter", "translator") builder.add_edge("translator", END) graph = builder.compile() # Compile & Run if __name__ == "__main__": input_text = "ai is taking over evrything developers must learn agents or get left behnd langchain langgraph is future" result = graph.invoke({"raw_input": input_text}) print("\n========== FINAL OUTPUT ==========") print(result["final_output"])

Project 2: Parallel Workflows & Reducers (parallel_reducers.py)

Preventing the "Last-Writer-Wins" disaster when multiple branches execute concurrently from START into END.

The Annotated Reducer Pattern
scores: Annotated[dict, merge_score_dicts]
When Toxicity, Copyright, and Culture nodes return partial dictionaries simultaneously, merge_score_dicts merges them into a unified dictionary instead of overwriting.
Python — parallel_reducers.py (Complete Production Code)
import os from typing import TypedDict, Annotated from dotenv import load_dotenv from langchain_groq import ChatGroq from langgraph.graph import StateGraph, START, END load_dotenv() llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.2) # Custom Reducer: Merges dictionaries emitted by parallel branches def merge_score_dicts(left: dict, right: dict) -> dict: """Combines two score dictionaries so parallel nodes don't overwrite each other.""" combined = left.copy() combined.update(right) return combined # State with Annotated Reducer class ContentSafetyState(TypedDict): raw_text: str scores: Annotated[dict, merge_score_dicts] final_verdict: str # Branch 1: Toxicity Analysis def toxicity_node(state: ContentSafetyState) -> dict: prompt = ( "Analyze this text for toxic language, insults, or harassment. " "Reply ONLY with a JSON-like key-value: 'toxicity_level': <0.0 to 1.0>.\n\n" f"Text: {state['raw_text']}" ) res = llm.invoke(prompt) return {"scores": {"toxicity_raw": res.content.strip()}} # Branch 2: Copyright & Plagiarism Check def copyright_node(state: ContentSafetyState) -> dict: prompt = ( "Check this text for potential copyrighted material, trademarks, or brand infringements. " "Reply ONLY with: 'copyright_risk': <LOW/MEDIUM/HIGH>.\n\n" f"Text: {state['raw_text']}" ) res = llm.invoke(prompt) return {"scores": {"copyright_raw": res.content.strip()}} # Branch 3: Regional & Cultural Sensitivity def culture_node(state: ContentSafetyState) -> dict: prompt = ( "Assess this text for cultural insensitivity, religious offense, or political bias. " "Reply ONLY with: 'cultural_insensitivity': <SAFE/FLAGGED>.\n\n" f"Text: {state['raw_text']}" ) res = llm.invoke(prompt) return {"scores": {"cultural_raw": res.content.strip()}} # Build Graph with Parallel Fan-Out builder = StateGraph(ContentSafetyState) builder.add_node("toxicity", toxicity_node) builder.add_node("copyright", copyright_node) builder.add_node("culture", culture_node) # Fan-out: All 3 nodes trigger simultaneously from START builder.add_edge(START, "toxicity") builder.add_edge(START, "copyright") builder.add_edge(START, "culture") # Fan-in: All 3 nodes complete into END builder.add_edge("toxicity", END) builder.add_edge("copyright", END) builder.add_edge("culture", END) app = builder.compile() # Test Input if __name__ == "__main__": sample = "Our brand new software completely crushes all competitors, they are absolute clowns!" out = app.invoke({"raw_text": sample, "scores": {}}) print("\nCombined Safety Dict:", out["scores"])

Project 3: Conditional Workflow & Multi-PDF RAG (conditional_RAG.py)

Dynamic query classification routing requests to specialist FAISS retrievers across academic, admission, placement, and exam policies.

Python — conditional_RAG.py (Complete Production Code)
import os from typing import TypedDict, List from dotenv import load_dotenv from langchain_community.document_loaders import PyPDFLoader from langchain_text_splitters import RecursiveCharacterTextSplitter from langchain_community.vectorstores import FAISS from langchain_openai import OpenAIEmbeddings, ChatOpenAI from langgraph.graph import StateGraph, START, END load_dotenv() embeddings = OpenAIEmbeddings() llm = ChatOpenAI(model="gpt-4o", temperature=0) # Step 1: Build RAG Retrievers def build_retriever(pdf_path: str): if os.path.exists(pdf_path): docs = PyPDFLoader(pdf_path).load() chunks = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50).split_documents(docs) db = FAISS.from_documents(chunks, embeddings) return db.as_retriever(search_kwargs={"k": 3}) return None academic_retriever = build_retriever("academics_handbook.pdf") fee_retriever = build_retriever("fee_structure.pdf") # Step 2: Define State class CollegeState(TypedDict): query: str programme: str query_type: str retrieved_docs: str final_answer: str # Step 3: Nodes def classifier_node(state: CollegeState) -> dict: prompt = ( "Classify this student question into EXACTLY one category:\n" "- ACADEMIC (syllabus, courses, attendance, exams)\n" "- FEE (tuition, scholarships, installments, fines)\n" "- GENERAL (campus life, library, clubs)\n\n" f"Question: {state['query']}\n" "Reply ONLY with the category name in lowercase." ) res = llm.invoke(prompt) category = res.content.strip().lower() return {"query_type": category} def academic_rag_node(state: CollegeState) -> dict: docs = academic_retriever.invoke(state["query"]) if academic_retriever else [] context = "\n".join([d.page_content for d in docs]) if docs else "Academic handbook not found." return {"retrieved_docs": context} def fee_rag_node(state: CollegeState) -> dict: docs = fee_retriever.invoke(state["query"]) if fee_retriever else [] context = "\n".join([d.page_content for d in docs]) if docs else "Fee policy not found." return {"retrieved_docs": context} def general_rag_node(state: CollegeState) -> dict: return {"retrieved_docs": "General guidelines: College hours 9 AM - 5 PM. Library open till 8 PM."} def response_node(state: CollegeState) -> dict: prompt = ( f"Student Programme: {state['programme']}\n" f"Retrieved Context:\n{state['retrieved_docs']}\n\n" f"Student Question: {state['query']}\n\n" "Provide a polite, grounded answer citing specific policies." ) res = llm.invoke(prompt) return {"final_answer": res.content} # Step 4: Conditional Router Function def route_query(state: CollegeState) -> str: category = state["query_type"] if "fee" in category: return "fee_rag" elif "academic" in category: return "academic_rag" return "general_rag" # Step 5: Build Graph builder = StateGraph(CollegeState) builder.add_node("classifier", classifier_node) builder.add_node("academic_rag", academic_rag_node) builder.add_node("fee_rag", fee_rag_node) builder.add_node("general_rag", general_rag_node) builder.add_node("responder", response_node) builder.add_edge(START, "classifier") builder.add_conditional_edges( "classifier", route_query, { "academic_rag": "academic_rag", "fee_rag": "fee_rag", "general_rag": "general_rag" } ) builder.add_edge("academic_rag", "responder") builder.add_edge("fee_rag", "responder") builder.add_edge("general_rag", "responder") builder.add_edge("responder", END) app = builder.compile() # Step 6: Interactive Terminal Execution if __name__ == "__main__": out = app.invoke({ "query": "What is the penalty for late fee payment?", "programme": "BCA", "query_type": "", "retrieved_docs": "", "final_answer": "" }) print("\nRoute:", out["query_type"]) print("Answer:", out["final_answer"])

Project 4: Iterative Workflow with Tools & Reviewer (iterative_tools.py)

Generator-Critic loop with Tavily live search tools and strict 7-criteria quality thresholding.

Python — iterative_tools.py (Complete Production Code)
import os from typing import TypedDict, Annotated, List from dotenv import load_dotenv from langchain_community.tools.tavily_search import TavilySearchResults from langchain_openai import ChatOpenAI from langchain_core.messages import BaseMessage, HumanMessage, AIMessage, SystemMessage from langgraph.graph import StateGraph, START, END load_dotenv() # Tools & Models tavily = TavilySearchResults(max_results=2) tools = [tavily] llm = ChatOpenAI(model="gpt-4o", temperature=0.7) llm_with_tools = llm.bind_tools(tools) # State class PostState(TypedDict): topic: str messages: List[BaseMessage] draft: str score: float feedback: str iterations: int # Step 1: Writer Node with Tool Execution def writer_node(state: PostState) -> dict: print(f"\n--- Writer Node (Iteration {state['iterations'] + 1}) ---") system_prompt = ( "You are an elite LinkedIn content creator. Draft a viral, professional post. " "If you need real-time data or facts, invoke the search tool. " "Format: Punchy hook, 3 short paragraphs with emojis, and a discussion question." ) if state["feedback"]: user_msg = f"Revise this draft according to feedback:\nFeedback: {state['feedback']}\nDraft:\n{state['draft']}" else: user_msg = f"Write a LinkedIn post about: {state['topic']}" messages = [SystemMessage(content=system_prompt), HumanMessage(content=user_msg)] ai_msg = llm_with_tools.invoke(messages) # Execute tools if requested if ai_msg.tool_calls: tool_results = [] for tc in ai_msg.tool_calls: res = tavily.invoke(tc["args"]) tool_results.append(str(res)) # Follow up with tool context followup = llm.invoke(messages + [ai_msg, HumanMessage(content=f"Tool Results:\n{tool_results}")]) draft = followup.content else: draft = ai_msg.content return {"draft": draft, "iterations": state["iterations"] + 1} # Step 2: Reviewer Node with 7 Evaluation Criteria def reviewer_node(state: PostState) -> dict: print("\n--- Reviewer Node Evaluating Draft ---") review_prompt = ( "Evaluate this LinkedIn post on 7 criteria: " "1) Hook strength 2) Readability 3) Factual value 4) Emojis 5) CTA 6) Tone 7) Engagement.\n" "Format response strictly as:\n" "SCORE: <float 0.0 to 10.0>\n" "FEEDBACK: <critique or APPROVED>\n\n" f"Draft:\n{state['draft']}" ) res = llm.invoke(review_prompt) content = res.content # Parse Score & Feedback score = 7.0 feedback = "Needs better hook." for line in content.split("\n"): if line.startswith("SCORE:"): try: score = float(line.split(":")[1].strip()) except: pass elif line.startswith("FEEDBACK:"): feedback = line.split(":")[1].strip() return {"score": score, "feedback": feedback} # Router Decisions def should_continue(state: PostState) -> str: if state["score"] >= 8.5 or state["iterations"] >= 3: print(f"Stopping! Score: {state['score']}, Iterations: {state['iterations']}") return END return "writer" # Build Graph builder = StateGraph(PostState) builder.add_node("writer", writer_node) builder.add_node("reviewer", reviewer_node) builder.add_edge(START, "writer") builder.add_edge("writer", "reviewer") builder.add_conditional_edges("reviewer", should_continue, {"writer": "writer", END: END}) graph = builder.compile()

Project 5: Human-in-the-Loop (humanintheloop.py)

Suspending execution with interrupt(), state checkpointing via MemorySaver, and resumption using Command(resume=...).

Python — humanintheloop.py (Complete Production Code)
import os from typing import TypedDict from dotenv import load_dotenv from langchain_openai import ChatOpenAI from langgraph.graph import StateGraph, START, END from langgraph.checkpoint.memory import MemorySaver from langgraph.types import interrupt, Command load_dotenv() llm = ChatOpenAI(model="gpt-4o", temperature=0.7) class HITLState(TypedDict): topic: str draft: str human_feedback: str is_approved: bool def generate_draft_node(state: HITLState) -> dict: print("\n--- Generating Draft ---") prompt = f"Write an official corporate announcement about: {state['topic']}" res = llm.invoke(prompt) return {"draft": res.content} def human_approval_node(state: HITLState) -> dict: """Suspends execution and yields draft to human.""" print("\n=== [PAUSE] Pausing for Human Approval ===") user_response = interrupt({ "message": "Please review the corporate announcement.", "draft": state["draft"] }) # Resumes here when Command(resume=...) is passed! if user_response.lower() == "approved": return {"is_approved": True, "human_feedback": "Approved as is."} else: return {"is_approved": False, "human_feedback": user_response} # Graph with Checkpoint Memory checkpointer = MemorySaver() builder = StateGraph(HITLState) builder.add_node("generator", generate_draft_node) builder.add_node("human_gate", human_approval_node) builder.add_edge(START, "generator") builder.add_edge("generator", "human_gate") builder.add_edge("human_gate", END) app = builder.compile(checkpointer=checkpointer) # Execution Driver with Thread Config if __name__ == "__main__": thread_config = {"configurable": {"thread_id": "exec-101"}} # Phase 1: Invocation up to interrupt state1 = app.invoke({"topic": "Quarterly Earnings Release"}, config=thread_config) print("Interrupted state snapshot:", state1) # Phase 2: Resume with Human Input state2 = app.invoke(Command(resume="approved"), config=thread_config) print("\nResume state complete:", state2)

Reference

The 6 Foundational Multi-Agent Topologies

Architectural blueprints for structuring collaborative LLM systems in production.

1. Sequential Pipeline

Linear hand-off (A → B → C). Predictable, deterministic, and easy to trace. Used in Project 1.

2. Hierarchical Supervisor

A central orchestrator routes subtasks to specialist subagents and evaluates their outputs.

3. Generator-Critic Loop

Writer generates, Critic reviews against score thresholds. Loops back until approved. Used in Project 4.

4. Parallel Fan-out

Simultaneous execution from START with Annotated Reducers merging branch state. Used in Project 2.

5. Conditional RAG Router

Query classification dynamically routes requests to specialist vector databases. Used in Project 3 & 6.

6. Human-in-the-Loop

Pausing execution with interrupt() and resuming with human review. Used in Project 5.
